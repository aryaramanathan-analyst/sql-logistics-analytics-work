# Warehouse Operations and KPI Analysis

## Project Overview

This project analyses simulated warehouse operations data using SQL. It
focuses on order fulfilment, shipment performance, inventory availability
and warehouse-level operational KPIs.

## Business Objectives

The analysis aims to answer the following questions:

1. How many orders are processed by each warehouse?
2. What percentage of orders are shipped on time?
3. Which warehouses have the longest average processing time?
4. Which products generate the highest order volume?
5. Which orders have breached their promised shipment date?
6. Which inventory records indicate potential stockout risk?
7. How does warehouse performance change month over month?
